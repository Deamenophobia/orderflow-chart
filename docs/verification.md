# Local verification

Verified on Windows with Node 22.14.0 and the in-app Chromium browser on
2026-10-28. Verification uses synthetic data, including fixtures imported through
the companion Book Replay CLI. Hosted CI runs the same automated checks.

## Automated checks

`npm test` passes five focused behavior cases covering snapshot ties and gaps,
replay cutoff, partial UTC candles, missing trade direction, invalid input,
Book Replay report conversion, viewport bounds and bubble size limits.
`npm run check` passes JavaScript syntax and module-size checks.

The recorded-trade fixture check validates actual SQLite-adapter output: native
DOWN prices, buy/sell/unknown direction, timestamp ties, distinct source-row IDs,
derived candle OHLC/counts and omission of wallet/transaction fields.

## Browser checks

- Loaded 109 synthetic book snapshots and 120 synthetic trades. The deliberate
  book gap leaves an empty band while independently recorded trades continue.
- Imported a report generated by the actual Book Replay CLI from its SQLite
  fixture: four full book frames, zero trades. No candles or bubbles were invented.
- Imported `examples/recorded-trades.json`, generated by that CLI from synthetic
  historical SQLite trades: one book snapshot and four trades. Inspection showed
  the expected buy at 0.58 / quantity 4.5, with sell and neutral trades retained.
- Imported the CLI's live-table output: one snapshot and two neutral trades.
  The first inspected record was `ticks:2`, price 0.58, quantity 5 and timestamp
  22:13:20.250 UTC. Missing source direction remained unknown. No warnings or
  errors appeared in the captured console during these two imports.
- Rejected an imported trade with side `UP`, retained the previous recording and
  displayed the validation error.
- Zoomed, panned within recording bounds and restored the viewport using Home.
- Toggled liquidity off while retaining candles and trade bubbles.
- Inspected a neutral trade from the accessible trade list; preserved its raw
  price, quantity, timestamp and ID.
- Hit-tested a bubble directly on the canvas and inspected an ask-liquidity band,
  including its source snapshot sequence and observation time.
- Reset and played the complete recording at 5×. The host reached the end and
  stopped. Manual seeking updated the visible trade list.
- Checked a 390px viewport: no horizontal document overflow. Restored the default
  viewport after the responsive check.

The demo has no external data services. The exact historical deployed chart
revision is still unresolved. Large-feed performance, additional browsers,
actual collector recordings and production embedding have not been validated.
